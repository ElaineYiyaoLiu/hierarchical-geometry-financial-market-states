# Branch B

Branch B develops the observable-data side of the study: preprocessing, candidate geometries, the common fitting pipeline, hierarchy-support analysis, uncertainty estimates, and output formatting.

## Data boundary

For blind validation and locked testing, work only from the information released with the observable datasets. Generator equations, latent labels, true hierarchies, hidden condition parameters, and other restricted Branch A material stay unavailable until the prediction freeze and approved truth release.

Method definitions and fitted-pipeline choices should be versioned before they are frozen for later stages.

## Week 1 setup records

- `geometry_registry.md` — proposed observable geometries and candidate Common Fitter
- `draft_cards/` — draft, explicitly non-frozen method cards
- `branch_b_environment.txt` — Python 3.14 requirement and environment-verification status
- `seed_namespace_b.yaml` — Branch B-owned stochastic namespace policy
- `schema_report_b.json` — shared-interface presence and conformance-run status
- `handoff_acknowledgement.md` — handoff acknowledgement draft

Open scientific specifications remain marked as pending rather than being silently fixed.
