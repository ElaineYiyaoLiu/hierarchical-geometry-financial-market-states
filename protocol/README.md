# Project protocol

This directory contains the protocol material that is safe to share across the project.

The study uses a blinded two-branch design. Branch A owns the synthetic data-generating process and ground truth. Branch B works from released observable datasets and develops the recovery pipeline. Shared materials cover the research question, data interface, validation rules, evaluation conventions, and the release/freeze process.

Restricted generator details and sealed scientific truth are kept outside this repository.

The shared protocol package will be versioned here before pilot exchange.
